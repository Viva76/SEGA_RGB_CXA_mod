# SEGA Mega Drive Clone RGB&AudioVideo Bypass Mod

![Плата мода](https://github.com/Viva76/SEGA_RGB_CXA_mod/blob/main/Images/SEGA_RGB_CXA_mod_pcb.jpg)

Модификация (мод-плата) для аппаратного улучшения клонов игровых приставок **Sega Mega Drive / Genesis**, выполненных на неполных (укороченных) материнских платах без установленного видео кодера. Предназначена для модификации клонов на мультипроцессоре SM-801A и аналогов для улучшения композитного видеосигнала, вывода RGB и стерео аудио. 

Конструктивно плата разработана для полной замены штатной интерфейсной платы (платы входа питания и AV-выхода). Она объединяет в себе лучшие наработки по качеству звука и картинки (**Mega Amp 2.0** и **RGB&AV** на базе чипа **SONY CXA2075**), выводя сигналы на стандартный разъем **miniDIN-9**. Размеры платы оптимизированы под большинство корпусов клонов на постсоветском пространстве и не превышают 100 мм для экономичного заказа в производстве.

## 🛠 Основные характеристики и возможности

### 1. Питание и защита
* **Защита от переполюсовки:** На входе установлен диодный мост `D1` (KBP208), защищающий плату и консоль от блоков питания с неверной полярностью.
* **Фильтрация помех:** Сглаживающий LC-фильтр (`L1`, `C5`) для минимизации шумов от некачественных импульсных БП.
* **Индикация:** Светодиоды `D2` и `D3` для индикации наличия питания +5V.
* **Интерфейс J2:** Через разъем `J2` на основную плату консоли выводятся внешнее питание, GND, +5V, композитное видео и моно-аудио.

### 2. Видео-тракт (RGB&AV)
Построен на базе высококачественного видеокодера **SONY CXA2075** (`U1`). Сигналы Red, Green, Blue, Синхронизация (C-Sync), Поднесущая (Fsc)  берутся напрямую с графического процессора (VDP) или мультипроцессорного чипа, полностью минуя штатный кодер приставки.
* **Согласование уровней:** Входные делители понижают сигналы с 5Vpp до стандартных 0.75Vpp (максимально допустимое зачение 1Vpp).
* **PAL/NTSC Select:** Джампера `J4` `J5` позволяют выбрать тип композитного видеосигнала в зависимости от настроек VDP и подаваемой поднесущей цветности Fsc.
* **Конфигурация синхронизации (Джампер JP3):** Выбирает сигнал синхронизации для pin-4 разъема miniDIN9:
  *  **Положение CVBS-4:** Для синхронизации используется композитное видео. Изображение совместимо со стандартными кабелями, но могут присутствовать вертикальные полосы (jailbars).
  *  **Положение 4-LUMA:** Для синхронизации используется яркостный сигнал LUMA. Потенциально уменьшает контрастность вертикальных полос на стадартном кабеле miniDIN9-SCART (с синхронизацией по pin-4), но композитное видео через стандартный AV-кабель в этом режиме пропадает. 
 
 Экспериментально разницы при разных типах синхроницации не замечено, рекомендация использовать в положении CVBS-4.

### 3. Аудио-тракт (Mega AMP)
В основе лежит модифицированная двухкаскадная схема **Mega Amp 2.0** на двухканальном операционном усилителе **TL972** (`U2`) в паре со специализированным микросхемным телефонным буфером **TDA1308** (`U3`). Номиналы обвязки операционных усилителей подобраны исходя из моих личных предпочтений на клоне с GOAC  SM-801A.  
* **Входной микшер:** Позволяет смешивать сигналы звукового тракта с основной платы (`MOL`, `MOR`, `PSG`), а также сигналы со слота картриджа (`SL1`, `SR1`).
* **Настройка PSG:** По умолчанию установлены нагрузочные элементы `R12`, `C14`. Если на вашей материнской плате клона уже есть нагрузка для PSG, удалите эти элементы либо на плате мода, либо на плате консоли.
* **Вывод:** Стереозвук выводится на pin-8 и pin-9 разъема miniDIN9. Моно-сигнал для стандартных кабелей берется напрямую от схемы усиления основной платы приставки через разъем `J2`.

### 4. Выбор региона (JP1, JP2, J5)
На плате предусмотрены посадочные места под переключатели регионов (`Japan/Overseas`, `PAL/NTSC`), которые коммутируются с основной платой через интерфейс `J5`.
